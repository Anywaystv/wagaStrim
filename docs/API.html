API setup

Create cameras, get links and reset publishing keys from your own dashboard. Examples use default ports; replace the addresses and secrets.

1. Create the control token

Open Setup on your server or computer. In Reachability, click Generate control token, save it in a password manager and restart WagaStrim.

Or run locally, then restart (Windows: use curl.exe):

curl -X POST http://127.0.0.1:7330/api/control/token

Returns {"token":"YOUR_SECRET","restartRequired":true} (201). Existing tokens are never overwritten. Find controlToken in config.json; its path appears in the startup log.

Keep the token on your backend. It controls all cameras; never give it to Moblin, OBS or browser code.

Replace or disable the control token

Stop WagaStrim. Replace controlToken in the config with a random password of at least 32 characters, then restart and update clients. Remove the field to disable the API.

2. Set the addresses

Stop WagaStrim, merge these fields into config.json without removing other settings, then restart:

{
  "publicHost": "192.168.1.50",
  "controlLan": true,
  "controlRemote": false
}

Set publicHost to your server's reachable IP or hostname. Without it, links use localhost. The Local/Remote toggles allow API clients; they do not open firewall ports or change camera access.

Ports: TCP 7333 API, TCP 7331 signaling, UDP 7332 media. TCP 7330 Setup stays local (use an SSH tunnel for a remote server). Cellular streaming needs reachable public media/signaling ports.

HTTP exposes secrets. Use HTTPS or an encrypted VPN for internet access.

HTTPS and reverse proxies

Set tlsCert, tlsKey and the certificate hostname as publicHost, then restart. Signaling and control use HTTPS on the same ports. A signaling publicUrl overrides media-link addresses but does not secure the control API. Protect that listener separately. Access toggles inspect the proxy's address, not forwarded headers.

3. Generate camera keys and links

Send a name (1–48 characters). Keep your token out of shared shell history and logs.

curl http://127.0.0.1:7333/control/ingests -H "Authorization: Bearer YOUR_SECRET" -H "Content-Type: application/json" -d '{"label":"Phone"}'
Windows PowerShell example 
$credential = Read-Host "Control token"
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:7333/control/ingests -Headers @{Authorization="Bearer $credential"} -ContentType application/json -Body '{"label":"Phone"}'

Returns 201 with camera settings and links (keys abbreviated):

{
  "id": "...",
  "label": "Phone",
  "senderKey": "s_...",
  "receiverKey": "r_...",
  "codecs": ["h264"],
  "delayMs": 2000,
  "links": {
    "moblin": "whip://192.168.1.50:7331/whip/s_...",
    "whip": "http://192.168.1.50:7331/whip/s_...",
    "whep": "http://192.168.1.50:7331/whep/r_...",
    "player": "http://192.168.1.50:7331/player/r_..."
  }
}
links.moblin
Paste into Moblin. HTTPS uses whips://.
links.whip
Publishing URL for other WHIP clients.
links.player
Browser preview or OBS Browser Source. Use H.264 + Opus; enable Control audio via OBS.
links.whep
Raw endpoint for WHEP receivers; not a webpage.

Keep both keys private. New cameras use H.264 and 2000 ms delay. AAC needs a compatible receiver; browser preview requires Opus. Use OBS for Twitch/Kick output.

4. Retrieve cameras and status

curl http://127.0.0.1:7333/control/ingests -H "Authorization: Bearer YOUR_SECRET"
curl http://127.0.0.1:7333/control/stats -H "Authorization: Bearer YOUR_SECRET"

List returns {"ingests":[...]} with keys and links. Stats returns each camera ID's status; live means a publisher is active.

Reset a stream key

curl -X POST http://127.0.0.1:7333/control/ingests/CAMERA_ID/reset-key -H "Authorization: Bearer YOUR_SECRET"

Returns 200 with the camera and updated links. The old sender key stops working and sessions disconnect. The preview link stays unchanged.

For your dashboard button: confirm, call from your backend, save the returned key and show the new sender link. WagaStrim's button is under Camera settings.

Creating or resetting again makes new keys. After a lost response, list cameras before retrying. Use camera IDs, not names.

Advanced: replace the camera list

PUT /control/ingests accepts {"ingests":[...]} and replaces the entire list. An empty list deletes all cameras. Use one list owner; there is no conflict detection.

Each camera has id (nonempty and unique), label, senderKey (s_ + 32 lowercase hex characters), receiverKey (r_ + 32 lowercase hex characters), codecs (h264, h265, av1), delayMs (0–10000) and optional syncGroup. Keys must be unique and cryptographically random. Strip the read-only links field from GET results before PUT. Missing cameras and changed keys/codecs disconnect sessions; 204 means saved.

Errors

400: invalid request · 404: wrong token, blocked address or missing camera/route · 409: token already exists · 429: slow down · 500: save failed; check logs.

Connection refused? Restart after creating the token, then check the address and firewall.
